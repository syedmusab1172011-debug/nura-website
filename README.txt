NURA - Pure by Nature website (flat folder: all files in one place, no images folder)

Upload ALL files directly to the repository root: index.html, every .webp and .jpg image, robots.txt, sitemap.xml, 404.html, .nojekyll

BEFORE PUBLISHING:
1. Replace YOUR-DOMAIN.com in index.html, robots.txt and sitemap.xml.
2. Put the real Facebook / Instagram / TikTok links in index.html (each appears twice).

GITHUB PAGES: Settings > Pages > Deploy from a branch > main > / (root) > Save.
CHANGING A PHOTO: replace the image file with the same file name.
